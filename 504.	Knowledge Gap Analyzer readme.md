 Knowledge Gap Analyzer Desktop App

A Python desktop application that helps learners identify weak topics and provides actionable recommendations to improve learning efficiency.

## Features
- Input topics and scores in `Topic, Score` format
- Detect knowledge gaps below a specified threshold
- Receive personalized recommendations
- Calculate average score for quick insight

## Installation
1. Make sure you have Python 3 installed
2. Install Tkinter (usually comes pre-installed with Python)
3. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/knowledge-gap-analyzer.git

Run the app:

python app.py
Usage

Enter your topic scores, one per line, using format Topic, Score

Set a knowledge gap threshold

Click "Analyze Gaps" to see your weak areas and recommendations

Example Input
CPU Architecture, 65
Memory Hierarchy, 50
Pipelining, 72
Virtual Memory, 60
Example Output
Topics needing attention:
1. Memory Hierarchy -> Score: 50.00, Gap: 20.00
   Recommendation: Revise cache mapping, cache levels (L1/L2/L3), and miss penalty concepts.
2. Virtual Memory -> Score: 60.00, Gap: 10.00
   Recommendation: Study paging, TLB behavior, page faults, and replacement algorithms.
